# Selected Projects

## Predicting Wildfire Severity in Northeastern Portugal
**April 2026 - June 2026**
- Created a Bayesian hierarchical model using `brms` to estimate wildfire size within Montesinho National Park in NE Portugal
- Calculated posterior distributions for impacts of meteorological variables such as wind speed and relative humidity
- Established predictions for wildfire severity on an entire spatial grid mapping out the entirety of the national park

## Causal Inference with Health Insurance Data
**January 2026 - March 2026**
- Estimated causal impact of health insurance type on hospital mortality and elopement rates
- Used data from MIMIC-IV, which was collected at the Beth Israel Deaconess Medical Center
- Employed augmented inverse propensity weighting (AIPW) based on linear regression to calculate causal effects


## Estimating Food Delivery Times with Statistical Learning using Python  
**November 2023 - January 2024**
- Used food delivery data from the Indian subcontinent to build predictive models with scikit-learn and XGBoost.  
- Wrangled data with the `polars` package and visualized figures using `seaborn` and `matplotlib`.  
- Achieved an average prediction error less than one-third of the standard deviation for delivery times.  

## Predicting Customer Churn with Machine Learning in Python  
**February 2023 - April 2023**
- Extracted datasets from an anonymous telecommunications firm and tidied data using `polars`.  
- Forecasted customer churn using scikit-learn and XGBoost.  
- Calculated business value of approximately $1.2 million annually per 10,000 customers.
